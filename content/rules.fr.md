# Le 30 octobre, montrez-nous votre costume !

Le concours de costumes d'Halloween du CRD revient. Les règlements détaillés arrivent bientôt.

**Comment ça marche**

1. Le jour du concours, scannez le code QR de l'affiche.
2. Connectez-vous avec votre courriel institutionnel (McGill, Douglas ou CIUSSS) : vous recevrez un code à 6 chiffres.
3. Inscrivez votre costume avec 1 à 3 photos, et votez pour votre préféré. Un vote par personne.
